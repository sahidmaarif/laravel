# Quick Start Guide - Authentication Testing

## Before You Start

Make sure your Laravel project is properly set up:

```bash
# Navigate to your project
cd c:\laravel\ project\onlineshop

# Install dependencies (if not done)
composer install
npm install

# Create environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Run migrations
php artisan migrate

# Start development server
php artisan serve
```

## Test Authentication Flows

### 1. **Test Registration**

```
URL: http://localhost:8000/register
- Fill in: Name, Email, Password, Confirm Password
- Click: Create Account
- Expected: Email verification page
```

### 2. **Test Email Verification**

```
After registration:
- Check your email (or logs in dev mode)
- Click verification link
- Expected: Redirected to dashboard
```

### 3. **Test Login**

```
URL: http://localhost:8000/login
- Email: your@email.com
- Password: your-password
- Optional: Check "Remember me"
- Click: Sign In
- Expected: Redirected to dashboard
```

### 4. **Test Forgot Password**

```
URL: http://localhost:8000/forgot-password
- Email: registered@email.com
- Click: Send Reset Link
- Expected: Confirmation message
- Check email for reset link
```

### 5. **Test Profile Management**

```
After login:
- Click navbar user dropdown
- Select "Profile"
- Expected: Profile page with three sections:
  - Update Profile Information
  - Update Password
  - Delete Account (danger zone)
```

### 6. **Test Logout**

```
- Click navbar user dropdown
- Select "Logout"
- Expected: Redirected to login page
```

## Common Issues & Solutions

### Issue: "View not found" error

**Solution:** Run these commands:

```bash
php artisan cache:clear
php artisan view:clear
php artisan config:clear
```

### Issue: CSRF token mismatch

**Solution:** Make sure your `.env` file has:

```
APP_KEY=base64:... (generated by php artisan key:generate)
SESSION_DRIVER=file
```

### Issue: Email verification not working in development

**Solution:** Check your logs:

```bash
tail -f storage/logs/laravel.log
```

Or enable log viewer in `config/logging.php`

### Issue: Database migrations not running

**Solution:**

```bash
php artisan migrate:fresh --seed
```

## Configuration Files

### Key Files to Know About

1. **config/app.php** - App name, locale
2. **config/auth.php** - Auth driver, guards
3. **config/mail.php** - Email settings
4. **.env** - Environment variables

### Important .env Settings

```env
APP_NAME="Online Shop"
APP_URL=http://localhost:8000

DB_CONNECTION=sqlite
DB_DATABASE=database/database.sqlite

MAIL_DRIVER=log  # Use 'log' for testing, 'smtp' for production
MAIL_FROM_ADDRESS=noreply@example.com
```

## Customization Guide

### Change App Name

Edit: `resources/views/components/navbar.blade.php`

```blade
<a class="navbar-brand fw-bold" href="{{ route('home') }}">
    <i class="bi bi-shop"></i> Your Shop Name  <!-- Change here -->
</a>
```

### Change Primary Color

Edit any view and replace `btn-primary` with:

- `btn-info` (light blue)
- `btn-success` (green)
- `btn-warning` (orange)
- `btn-danger` (red)

### Change Navbar Color

Edit: `resources/views/components/navbar.blade.php`
Replace `bg-dark` with:

- `bg-primary` (blue)
- `bg-success` (green)
- `bg-info` (light blue)
- `bg-warning` (orange)

### Add Custom CSS

Add styles to: `resources/css/app.css`

```css
.custom-class {
    /* Your styles */
}
```

## Email Testing in Development

### Option 1: Log Driver (Easiest)

In `.env`:

```env
MAIL_DRIVER=log
```

Emails will appear in `storage/logs/laravel.log`

### Option 2: Mailhog (Visual Testing)

```bash
# Download Mailhog from https://github.com/mailhog/MailHog/releases
# Run it: ./mailhog
# Set in .env:
MAIL_HOST=localhost
MAIL_PORT=1025
MAIL_DRIVER=smtp
```

Then visit: http://localhost:8025
